# App name options

These are options for the owner to choose. No replacement name has been selected or applied to the installed app, manifest or icons. The refreshed Home uses functional screen headings while that decision is pending.

| Option | Character |
| --- | --- |
| Wordbound | Connects books, vocabulary and the habit of returning to a story. |
| Pagewise | Reading a little at a time while becoming more confident. |
| Lilt | Short and warm, with an association to language, rhythm and listening. |
| Between Lines | Suggests finding meaning through reading and an accompanying language guide. |
| Storyling | Makes the connection between stories and language learning explicit. |
| Lingrove | A broader name for a growing personal language library. |

After the owner chooses, update the web title, installed app name, manifest short name and related metadata together in a separate reviewed change. This proposal does not choose a name or claim trademark/domain availability.
